## 📖 Overview

**AirWise** is a modern urban air quality assistant designed to help people understand their surroundings and make smarter everyday decisions.

Air pollution is more than just a number. AirWise transforms air quality information into simple, actionable insights through an interactive dashboard, daily planning tools, indoor air awareness, and sustainable lifestyle suggestions.

Whether you're planning your day or checking your indoor environment, AirWise helps you make more informed choices.

---

## ✨ Features

- 🌍 **Air Quality Dashboard** — Monitor AQI, PM2.5, PM10 and air quality categories.
- 📊 **Interactive AQI Visualization** — Understand pollution levels through visual indicators.
- 🗓️ **Smart Daily Planner** — Get activity suggestions based on air quality conditions.
- 🤖 **Ask AirWise** — Explore air-quality guidance through an assistant demo.
- 🏠 **Indoor Air Quality Checker** — Review room size, ventilation and purifier-related factors.
- 🌱 **Sustainable Choice Tracker** — Explore everyday choices and their environmental implications.
- 📚 **Air Quality Education** — Learn about pollution, exposure and healthier habits.
- 📱 **Responsive Interface** — Designed for desktop, tablet and mobile screens.

## 🚀 Getting Started

Follow these steps to run AirWise locally.

### 1. Clone the repository

```bash
git clone https://github.com/kktdroid52/AirWise.git
```

### 2. Navigate to the project directory

```bash
cd AirWise
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

---

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
```

To run unit tests:

```bash
npm test
```

---

## ⚙️ Environment Configuration

AirWise supports an optional assistant endpoint.

1. Copy `.env.example` to `.env`.
2. Configure `VITE_ASSISTANT_ENDPOINT` if you have your own backend endpoint.
3. Keep all private API keys on the server side.

**Note:** The assistant operates in rule-based demo mode when no endpoint is configured.

---

## 🌤️ Data Sources

AirWise uses the free **Open-Meteo Geocoding and Air Quality APIs**.

- Air quality data is based on modelled estimates.
- These estimates are not direct ground-station measurements.
- Simulated data is clearly labelled when live data retrieval fails.
